# Add a data source
1. Add an entry to `config/sources.yaml`: table, keys, date columns, amount, owner, spec FR.
2. Copy `src/plugins/_template.py` to `src/plugins/<source>.py`; read with the declared keys and dates only.
3. If a new output table is produced, add it to `contract.yaml`.
4. Tests: key uniqueness, date ranges, reconciliation to the finance or enrollment total.
5. Data Gate evidence is regenerated by the stage job.
